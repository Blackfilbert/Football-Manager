# Football Manager Copy - Project Instructions

## Overview
This is an **exact 1:1 copy** of the Real Football Manager Tycoon app, created for testing new mechanics. The source was copied from `/home/ubuntu/football_manager_source/football_manager_tycoon/react_native_space/`.

## Key Changes from Original
- **Bundle ID**: `com.abacusai.footballmanager.t1780663824` (both iOS and Android)
- **App Name**: "Football World Tour Tycoon"

## Tech Stack
- React Native 0.81, Expo SDK 54, TypeScript
- expo-router for navigation (file-based routing)
- @shopify/react-native-skia for graphics
- AsyncStorage for data persistence (frontend-only, no backend)
- react-native-paper for UI components

## Project Structure
- `app/` - expo-router screens (tabs layout with 11 tab screens)
- `src/context/GameContext.tsx` - Main game logic (1696 lines)
- `src/components/` - 19 UI components
- `src/services/` - ads, analytics, appsflyer, IAP
- `src/valorGP/` - Valor GP game mode
- `assets/` - 63+ images, sounds
- `plugins/` - custom Expo config plugins

## Architecture
- Frontend-only app with AsyncStorage persistence
- GameContext provides all game state and logic
- Tab-based navigation: 4 main tabs (Home, Team, Activity, Shop) + hidden tabs (Settings, Ratings, Career, Streetcup, Valorgp)
- **Team tab** (`teamhub.tsx`) contains 3 sub-tabs: Transfers, My Team, Scout — rendered as components from `src/screens/`. Sub-tab bar sits above main tab bar.
- Multiple game modes: League (stadiums), Career, Street Cup, Valor GP

## Stadium System (replaces Leagues)
- 30 stadiums from "Street Pitch" (local) → "Stadion Madrid" (final)
- Uses same `LEAGUES` array and `LeagueConfig` interface — `city` and `flag` fields added
- **No relegation** — only promotion (top 3 finish) or stay. Relegation code removed from GameContext, Header, and SeasonCompleteModal.
- **Prestige mechanic**: On promotion, all income upgrades (tickets, stadium, marketing, parking) reset to level 0. Income multiplier increases with each stadium (×1.0 → ×2.9).
- **Multiplier display**: Shown in LocationsModal rows and SeasonCompleteModal promotion info.
- Opponent power scales exponentially: `399 * 1.085^idx` to `600 * 1.085^idx`
- Win bonus: `1000 * 1.15^idx * 1.05^matchPlayed`
- Trophy rewards: `base = 8 + floor(idx * 1.5)`, 1st/2nd/3rd = base/70%/35%. Consolation trophies for non-promoted finishers: `max(1, floor(1 + leagueIdx*0.3))`
- AI standings basePower: `420 * 1.085^idx`
- Opponent name pools cycle through 5 sets (A–E) based on tier
- Blue location button in Header shortcut row (right side) → opens LocationsModal
- LocationsModal: bottom sheet (70% max height) with reversed list (top=hardest), CDN flag images, lock/check icons, "HERE" badge, multiplier per row, auto-scroll to current stadium
- **Flag system**: `flag` field in LEAGUES stores emoji flags directly (🇲🇹, 🇨🇾, 🏠, 🏟️). `FlagIcon` component renders them as Text with Twemoji Country Flags web font for Windows/Chromium compatibility. Font injected in `app/_layout.tsx` via CDN (`country-flag-emoji-polyfill`).
- **Multiplier**: Integer values ×1 through ×30 (one per stadium). Displayed with money icon (💲) in LocationsModal and SeasonCompleteModal.
- **Home screen sub-tabs** (bottom bar, teamhub style): "Match" (LiveMatch + power upgrades) and "Workspace" (compact income ×N banner + 3 income buildings as vertical list). Income buildings: Tickets 🎟️ (1/click), Marketing 📢 (5/click), Merch 👕 (15/click).
- **Income threshold progression**: Buildings get multipliers at levels 10(×2), 30(×2), 50(×1.5), 80(×1.5), 120(×1.5). Formula: `incomePerClick * level * (applicable mults)`. Functions: `getBuildingIncome()`, `getNextThreshold()` in utils.ts. UpgradeCard has `listMode` prop for vertical layout with threshold hints.
- **Staff system**: 33 total staff cards across 3 roles:
  - **Marketers (15)**: 5 rare/5 epic/5 legendary. Assigned to income buildings (tickets/marketing/merch). Bonus formula: baseMult×stars×level applied to building income.
  - **Trainers (9)**: 3 rare/3 epic/3 legendary (tr1-3/te1-3/tl1-3). Assigned to Training Hall or Strategy Room.
  - **Doctors (9)**: 3 rare/3 epic/3 legendary (dr1-3/de1-3/dl1-3). Assigned to Infirmary.
  - Stars from copies [1,2,4,8,16], levels 1-10 (**fame** cost=3+level×2). Box: 15 crystals, 60%/30%/10%.
  - Staff tab is 3rd main tab (briefcase icon), has role tabs (Marketers/Trainers/Doctors). Red dot badge when free opens available.
  - **Staff tab + special buildings unlock at leagueIndex >= 1** (2nd stadium "City Stadium").
  - **Free staff opens**: 2 free box openings granted on each promotion starting from stadium 2. First 4 opens have guaranteed roles: marketer → trainer → trainer → doctor.
  - **Staff Packs** section in Shop (visible when leagueIndex >= 1): free box (when available) + crystal box (15💎).
  - **Valor GP + Street Cup** unlock at leagueIndex >= 2 (3rd stadium "Stadion Valletta").
- **Illness system**: Chance scales with stadium: `stIdx >= 2 ? 0.05 + (stIdx-2)*0.012 : 0` (5% at stadium 2, ~38% at stadium 29). A random healthy starter gets ill. 4 types: Cold (70% effectiveness, weight 40), Fracture (50%, 30), Depression (30%, 20), Torn Ligament (10%, 10). Illness reduces player's effective overall in team power calc. PlayerCard shows illness badge + text.
- **Special Buildings** (rendered in Workspace via SpecialBuildings component when leagueIndex >= 1):
  - **Training Hall**: Assign trainer → train a player for +10-25% stat boost lasting 10 min, 3 min cooldown between trains.
  - **Strategy Room**: Assign trainer → generates 3 strategies every 5 min (max 9). Activate for 5-20% team power boost lasting 2 min.
  - **Infirmary**: Assign doctor → instantly heal a sick player.
- Staff state: `staff`, `staffAssigned`, `trainingBoosts`, `activeStrategies`, `strategiesReady`, `strategyLastGenTime`, `trainingCooldown` in GameState.
- `calculateTeamPower()` accounts for illness, training boosts, and active strategies.
- **Stadium earnings**: `stadiumEarnings` field in GameState tracks all money earned during current stadium stay. Reset to 0 on promotion or staying. SeasonCompleteModal shows total stadium earnings (not promotion reward). **On promotion: money resets to $0, trophies are kept, ALL PLAYERS KEPT (no squad wipe).** `playerSaleValue` always 0. `stadiumEarnings` field added to `SeasonCompleteInfo`.
- **Transfer player stats scale with stadium**: `STAT_GROWTH_PER_STADIUM` in utils.ts — common +5.5/stadium, rare +6, epic +7, legendary +8, icon +9, ultimate +10. Applied to overallMin/overallMax in `generatePlayer`.
- **Player cost scaling**: Market uses `costMult = max(1, leagueMult - 1)` so costs lag income by 1 multiplier.
- **Win reward scaling**: Win bonus multiplied by `leagueMult`.
- **Strategy generation**: First gen at 10s (`STRATEGY_GEN_FIRST`), subsequent at 5min. Batch size 1, duration 1min. Skip button available in SpecialBuildings.
- **Staff box tiers**: Normal (15💎: 89/10/0.5%), Epic (50💎: 50/45/5%), Legendary (100💎: 50/50%). 3rd free open guarantees rare trainer, 4th guarantees epic trainer.
- **Staff offers**: Deferred activation via `pendingStaffBoxOffer`/`pendingEpicStaffOffer` flags in GameState. Offer 1 at 2nd staff ($7.99 → 5× legendary marketer + 10 normal + 5 epic boxes, 12h timer). Offer 2 at 4th/epic ($4.99 → 8× copies of that epic + 3 epic boxes + 500 fame, permanent). `activateStaffOffers()` converts pending→shown. Modals rendered on Home, Staff, and Shop tabs.
- **Healing UI**: Green cross ✚ badge on PlayerCard when `healingUntil > now`. Countdown timer in PlayerInfoModal STATUS EFFECTS section.
- **Shop staff packs**: 3 box tiers (Normal 📦 15💎, Epic 💜 50💎, Legendary 🌟 100💎) + free box + offer banner lines for active offers.
- **Crystal skip → shop**: Training, strategy, heal skip buttons navigate to `/tabs/shop` when insufficient crystals.
- **Staff boxes removed from Staff tab**: "Open Staff Boxes in Shop" button navigates to shop instead.
- **Career player → My Team tab**: Career tutorial "Place in Team" passes `?tab=myteam` query param to teamhub. teamhub reads param via `useLocalSearchParams` and switches activeTab.

## Currencies
- **Money (soft)** — green dollars, earned via income/s and match bonuses
- **Fame (new)** — golden coin with trophy icon, earned per match: 7 for win, 5 for loss/draw. Displayed in header between money and diamonds.
- **Crystals (hard)** — purple diamonds, premium currency
- **Trophies** — earned for league season top-3 finishes (used in Career mode)
